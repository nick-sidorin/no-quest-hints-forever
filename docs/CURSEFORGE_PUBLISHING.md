# CurseForge listing maintenance

- [Edit the description](https://authors.curseforge.com/#/projects/1784092/description)
- [Public addon page](https://www.curseforge.com/wow/addons/no-quest-hints)

Copy the entire contents of [CURSEFORGE_DESCRIPTION.md](../CURSEFORGE_DESCRIPTION.md) into the full-description Markdown field. That file contains public description text only: no maintainer instructions, field labels, editor links or short description.

Copy the entire contents of [CURSEFORGE_SHORT_DESCRIPTION.txt](../CURSEFORGE_SHORT_DESCRIPTION.txt) into the short-description field. It contains only the plain-text value.

Keep both files current when user-facing features change and link to them plus the editor in release handoffs. Preserve compact benefits first, with quest features before secondary price/HUD controls, emoji headings and separate Issues/Source Code links. Put all maintainer instructions in this document, never in the copyable field files.

The owner updates the listing manually. Publishing a GitHub release or CurseForge package does not update these description fields automatically. These files are development/publishing assets and must stay outside installable addon packages.
