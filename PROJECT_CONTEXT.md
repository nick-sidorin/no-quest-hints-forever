## Активная задача: равноправные цены и короткие тексты

[PR #20](https://github.com/nick-sidorin/no-quest-hints-forever/pull/20), draft, ветка **feat/auction-vendor-prices**, база 10a063159c08c6b3f1511b4f2101670aa62cbc10. Начальный preview 3cc8dff268258f049a39d824e3391426ac890176 уже прошёл CI и был передан владельцу.

После игрового скриншота владелец отказался от вложенной положительной галочки. Актуальное согласованное решение:
- Группа «Цены предметов» / «Item prices» с двумя одинаковыми равноправными независимыми галочками: «Скрывать вне торговли» / «Hide outside trading» и «Скрывать на аукционе» / «Hide at auction». Обе по умолчанию OFF, без parent initializer и disabled predicate.
- У торговца цены всегда видны; на аукционе применяется только второй флаг, вне обоих торговых окон только первый. Цена — native SellPrice для NPC, не рыночная оценка аукциона. Modern и legacy auction frame поддерживаются; IsVisible приоритетнее IsShown.
- Владелец отдельно ответил: при выборе «Полного погружения» цены на аукционе **оставлять видимыми**. Поэтому Full = outside ON, auction OFF; остальные два пресета = оба OFF. Профили задают все семь чекбоксов. Вне применения пресета /reload сохраняет ручной выбор; restore/defaults выключают оба ценовых флага.
- SavedVariables: hideSellPrices и hideAuctionSellPrices. Миграция старого preview: auctionHidden = old hideSellPrices == true AND old showAuctionSellPrices == false. Это сохраняет действующую видимость, а не прежнюю неактивную оговорку. Старый положительный ключ удаляется; явный новый hideAuctionSellPrices сохраняется. Миграция идёт после определения первого запуска.
- Средняя карточка теперь только «Квестовые подсказки скрыты. Читайте задания и находите путь самостоятельно». Правая — всё из Погружения плюс скрытие цен вне торговли. Без списков, таблицы тарифов и упоминания цен в среднем варианте. ruRU/enUS сделаны одновременно.

Локально проходят 11 наборов Lua 5.1.5, включая матрицу 2×2 независимых ценовых галочек, merchant/auction/legacy/late-load, миграцию старого preview, reload/alt, пресеты и restore. Перед передачей проверить CI актуального head и byte-verified ZIP. Ценовой PR остаётся на проверку владельцем в Forever; релиз не запрошен.

## Устойчивые решения по интерфейсу

- Три режима: «Как у Blizzard» — ничего не скрывать; «Погружение» — пять квестовых функций; «Полное погружение» — квестовые функции и скрытие цен вне торговли; цены на аукционе видны, пока игрок отдельно не включит их скрытие.
- Первый запуск определяется onboardingComplete, а не количеством выключенных галочек. Закрытие/Later оставляет незавершённый выбор. Старые пользователи сохраняют настройки. Повторно открыть можно из /nqh → «Выбрать стиль игры».
- Карточки — Mode-Selection-Card-Regular, CircleMask, Mode-Selection-Ring в native размерах; одна рамка. Основная кнопка SharedGoldRedButtonExtraLargeTemplate и две симметричные SharedButtonSmallTemplate.
- Полноэкранный не масштабируемый modal shield блокирует мышь/колесо; дочернее окно масштабируется. Shield снимается при любом закрытии. Никаких глобальных хуков tooltip/OnUpdate.
- /nqh, /nqh restore, /nqh status. Старые on/off удалены и лишь показывают help.
- Семь галочек по умолчанию OFF, изменения только по выбору. Изначальные личные CVar сохраняются/восстанавливаются; незавершённые неудачные записи оставляют backups. На нормальном logout есть попытка восстановления без потери выбора. Аварийный выход/уже выгруженный аддон не гарантируют cleanup.
