## Активная отдельная задача: цены на аукционе

Владелец попросил сначала завершить/слить layout, затем открыть отдельный PR для аукционной галочки. Layout слит, изменения цен готовятся в ветке **feat/auction-vendor-prices**, база 10a063159c08c6b3f1511b4f2101670aa62cbc10.

- Короткая подпись: «Показывать на аукционе» / «Show at auction». В native Settings это вложенная настройка под скрытием цен в Additional immersion.
- По умолчанию ON для новых и существующих персонажей; можно выключить ради строгого RP. Это исходное решение реализации, озвученное владельцу при начале работы.
- Сохранение: NoQuestHintsForeverChar.showAuctionSellPrices. Независимая настройка исключения, а не седьмая функция скрытия.
- При скрытии цен торговец всегда показывает native SellPrice. Открытый AuctionHouseFrame или legacy AuctionFrame показывает цену только при включённом исключении. При закрытом аукционе исключение не действует. IsVisible имеет приоритет над IsShown, чтобы скрытый родитель не считался открытым окном.
- Цена — сумма продажи NPC, не рыночная цена, не себестоимость и не оценка аукциона. Не трогаем auction transactions/комиссии, данные предметов или отдельные оверлеи цен других аддонов.
- Выбор OFF сохраняется при /reload, смене пресета и /nqh restore. Restore выключает само скрытие цен, поэтому оставленное значение исключения не имеет эффекта. Native defaults возвращает исключение в ON.
- Новая настройка добавляется после определения первого запуска, чтобы не сломать автоматический онбординг нового персонажа.
- ruRU/enUS подписи, tooltip и status, README/CurseForge draft/changelog обновлены.

## Устойчивые решения по интерфейсу

- Три режима: «Как у Blizzard» — ничего не скрывать; «Погружение» — пять квестовых функций; «Полное погружение» — все шесть, включая скрытие цен. Аукционная оговорка управляется отдельной галочкой.
- Первый запуск определяется onboardingComplete, а не количеством выключенных галочек. Закрытие/Later оставляет незавершённый выбор. Старые пользователи сохраняют настройки. Повторно открыть можно из /nqh → «Выбрать стиль игры».
- Карточки — Mode-Selection-Card-Regular, CircleMask, Mode-Selection-Ring в native размерах; одна рамка. Основная кнопка SharedGoldRedButtonExtraLargeTemplate и две симметричные SharedButtonSmallTemplate.
- Полноэкранный не масштабируемый modal shield блокирует мышь/колесо; дочернее окно масштабируется. Shield снимается при любом закрытии. Никаких глобальных хуков tooltip/OnUpdate.
- /nqh, /nqh restore, /nqh status. Старые on/off удалены и лишь показывают help.
- Шесть функций по умолчанию OFF, изменения только по выбору. Изначальные личные CVar сохраняются/восстанавливаются; незавершённые неудачные записи оставляют backups. На нормальном logout есть попытка восстановления без потери выбора. Аварийный выход/уже выгруженный аддон не гарантируют cleanup.
